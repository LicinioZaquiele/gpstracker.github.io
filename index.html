Sobre o Projeto

Este projeto consiste no desenvolvimento de um ecossistema completo de rastreamento geográfico através da Internet das Coisas (IoT). O protótipo combina hardware embebido otimizado para baixo consumo energético com uma infraestrutura de rede robusta para garantir que a localização de um objeto, veículo ou pessoa esteja sempre acessível à distância de um clique.

📍

Geolocalização GNSS

Ligação rápida a múltiplas constelações de satélites para obter dados de latitude, longitude e altitude com elevada precisão.

📡

Conetividade IoT

Transmissão segura de pacotes de telemetria através de protocolos eficientes (como MQTT ou HTTP) adaptados a redes móveis ou LoRaWAN.

🚧

Mecanismo Geofencing

Criação de barreiras virtuais no mapa com envio imediato de alertas analíticos sempre que o perímetro estipulado for violado.

Arquitetura e Fluxo de Dados

1

Aquisição (Nó Sensor)

O módulo de hardware calcula a posição atual processando os sinais de rádio dos satélites em órbita.

2

Gateway / Nuvem

O microcontrolador empacota as coordenadas e envia-as encriptadas para o broker ou servidor de dados.

3

Aplicação Web

O dashboard processa o histórico, armazena as rotas e renderiza o posicionamento atual em mapas interativos.
